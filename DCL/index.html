Instrucciones DCL

Data Control Language

DCL agrupa las instrucciones SQL utilizadas para controlar los permisos y privilegios de los usuarios dentro de una base de datos.
🔓

GRANT

Permite otorgar permisos a uno o más usuarios para realizar determinadas operaciones sobre una base de datos.

GRANT SELECT, INSERT
ON escuela.*
TO 'usuario'@'localhost';
🔒

REVOKE

Permite quitar permisos que habían sido otorgados previamente a un usuario.

REVOKE INSERT
ON escuela.*
FROM 'usuario'@'localhost';
