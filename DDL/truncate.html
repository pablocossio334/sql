1. ¿Qué hace TRUNCATE TABLE?

La instrucción TRUNCATE TABLE elimina todos los registros almacenados dentro de una tabla.

A diferencia de DROP TABLE, la tabla continúa existiendo.

Es decir, se eliminan los datos pero se conserva la estructura.

↑ Subir | ↓ Siguiente

2. Sintaxis general

TRUNCATE TABLE nombre_tabla;

Por ejemplo: 

TRUNCATE TABLE alumnos;

Esto elimina todos los registros de la tabla alumnos.

↑ Anterior | ↓ Siguiente

Antes de TRUNCATE

idAlumno    nombre
-------------------
1           Ana
2           Juan
3           Pedro

Ejecutamos: 

TRUNCATE TABLE alumnos;

Después: 

idAlumno    nombre
-------------------

La tabla continúa existiendo, pero ahora está vacía.

3. ¿Qué se conserva?

Columnas

Las columnas de la tabla siguen existiendo.

Tipos de datos

Los tipos de datos permanecen sin cambios.

PRIMARY KEY

La clave primaria continúa definida.

Restricciones

Las restricciones de la tabla forman parte de su estructura y se conservan.

4. AUTO_INCREMENT

En MySQL y MariaDB, TRUNCATE TABLE normalmente reinicia el contador de una columna AUTO_INCREMENT. 

CREATE TABLE alumnos (

    idAlumno INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100)

);

Supongamos que tenemos: 

idAlumno
---------
1
2
3
4

Ejecutamos: 

TRUNCATE TABLE alumnos;

El próximo registro normalmente comenzará nuevamente desde: 

idAlumno = 1

5. TRUNCATE y WHERE

TRUNCATE no permite utilizar WHERE.

Siempre elimina todos los registros de la tabla. 

TRUNCATE TABLE alumnos;

Esto NO es válido: 

TRUNCATE TABLE alumnos
WHERE edad < 18;

Si queremos eliminar solamente algunos registros, debemos utilizar DELETE. 

DELETE FROM alumnos
WHERE edad < 18;

6. TRUNCATE y FOREIGN KEY

Si una tabla está siendo referenciada por una FOREIGN KEY, MySQL puede impedir ejecutar TRUNCATE. 

cursos
   ↑
   |
alumnos.idCurso

Esto ocurre para proteger las relaciones entre las tablas.

Por ejemplo, si alumnos.idCurso referencia a cursos.idCurso, debemos tener en cuenta esa relación antes de vaciar las tablas.

7. DELETE vs TRUNCATE

DELETE

Permite eliminar todos los registros o solamente algunos. 

DELETE FROM alumnos
WHERE edad < 18;

TRUNCATE

Elimina siempre todos los registros. 

TRUNCATE TABLE alumnos;

TRUNCATE vs DROP TABLE

TRUNCATE

Elimina los datos, pero conserva la tabla. 

TRUNCATE TABLE alumnos;

DROP TABLE

Elimina los datos y también la estructura. 

DROP TABLE alumnos;

Comparación rápida

DELETE
     ↓
Elimina registros
Puede usar WHERE
Conserva estructura


TRUNCATE
     ↓
Elimina TODOS los registros
No usa WHERE
Conserva estructura


DROP TABLE
     ↓
Elimina registros
+
Elimina estructura

8. ¿Cuándo usar TRUNCATE?

Vaciar una tabla

Cuando necesitamos eliminar todos sus registros.

Conservar la tabla

Cuando queremos seguir utilizando la misma estructura.

Datos de prueba

Puede utilizarse para limpiar una tabla después de realizar pruebas.

Reiniciar datos

Cuando queremos comenzar nuevamente con una tabla vacía.

9. ⚠️ Atención

TRUNCATE TABLE es una operación que elimina todos los registros de la tabla.

No podemos indicar qué filas queremos eliminar, porque no admite una condición WHERE. 

TRUNCATE TABLE alumnos;
        ↓
Se eliminan TODOS
los registros

Antes de ejecutarlo debemos asegurarnos de que realmente queremos vaciar completamente la tabla.
