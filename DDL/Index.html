Instrucciones DDL

Data Definition Language

DDL agrupa las instrucciones SQL utilizadas para crear, modificar y eliminar la estructura de una base de datos.
➕

CREATE

Permite crear nuevos elementos dentro de una base de datos, como bases, tablas o vistas.

CREATE TABLE alumnos (...);
🛠️

ALTER

Permite modificar la estructura de una tabla que ya existe.

ALTER TABLE alumnos ADD edad INT;
🗑️

DROP

Elimina completamente un objeto de la base de datos junto con su estructura.

DROP TABLE alumnos;
🧹

TRUNCATE

Elimina todos los registros de una tabla conservando su estructura.

TRUNCATE TABLE alumnos;
✏️

RENAME

Permite cambiar el nombre de un objeto existente, como una tabla.

RENAME TABLE alumnos TO estudiantes;
