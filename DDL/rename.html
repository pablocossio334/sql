1. ¿Qué hace RENAME?

La instrucción RENAME permite cambiar el nombre de un objeto que ya existe dentro de la base de datos.

Se utiliza principalmente para cambiar el nombre de tablas.

También podemos renombrar columnas utilizando ALTER TABLE.

↑ Subir | ↓ Siguiente

2. RENAME TABLE

En MySQL y MariaDB podemos utilizar RENAME TABLE para cambiar el nombre de una tabla. 

RENAME TABLE alumnos
TO estudiantes;

La tabla alumnos pasa a llamarse estudiantes.

Solamente cambió el nombre de la tabla.

3. RENAME con ALTER TABLE

También podemos cambiar el nombre de una tabla utilizando ALTER TABLE. 

ALTER TABLE alumnos
RENAME TO estudiantes;

El resultado es el mismo: la tabla conserva sus datos y estructura, pero cambia de nombre.

4. Renombrar una columna

Para cambiar el nombre de una columna podemos utilizar ALTER TABLE junto con RENAME COLUMN. 

ALTER TABLE estudiantes
RENAME COLUMN nombre
TO nombreCompleto;

La columna nombre pasa a llamarse nombreCompleto.

5. Renombrar varias tablas

En MySQL y MariaDB se pueden renombrar varias tablas en una sola instrucción. 

RENAME TABLE

alumnos TO estudiantes,

cursos TO materias,

docentes TO profesores;

Cada tabla recibe su nuevo nombre dentro de la misma instrucción.

6. ¿Qué se conserva?

Al renombrar una tabla no estamos eliminando ni reconstruyendo su contenido.

Datos

Los registros almacenados permanecen en la tabla.

Columnas

Las columnas continúan formando parte de la tabla.

Tipos de datos

Los tipos de datos permanecen sin cambios.

PRIMARY KEY

La clave primaria continúa definida.

FOREIGN KEY

Las restricciones continúan formando parte de la estructura.

Índices

Los índices propios de la tabla continúan existiendo.

7. Precauciones al renombrar

Cambiar el nombre de una tabla puede afectar otros elementos que utilicen ese nombre.

Aplicaciones

El código puede seguir intentando consultar el nombre anterior.

Consultas

Consultas SQL guardadas pueden utilizar el nombre antiguo.

Vistas

Conviene revisar vistas que dependan de la tabla.

Por ejemplo, si teníamos: 

SELECT *
FROM alumnos;

y la tabla ahora se llama estudiantes, la consulta deberá actualizarse: 

SELECT *
FROM estudiantes;

8. RENAME vs DROP

RENAME

Cambia el nombre del objeto, pero lo conserva. 

RENAME TABLE alumnos
TO estudiantes;

DROP

Elimina completamente el objeto. 

DROP TABLE alumnos;

Comparación rápida

RENAME
    ↓
Cambia el nombre
    ↓
Datos permanecen
    ↓
Estructura permanece


DROP
    ↓
Elimina el objeto
    ↓
Datos eliminados
    ↓
Estructura eliminada

9. Ejemplo paso a paso

Creamos inicialmente una tabla: 

CREATE TABLE alumnos (

    idAlumno INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100),

    edad INT

);

Después decidimos cambiar el nombre de la tabla: 

RENAME TABLE alumnos
TO estudiantes;

Ahora podemos consultar: 

SELECT *
FROM estudiantes;

Luego decidimos cambiar el nombre de una columna: 

ALTER TABLE estudiantes
RENAME COLUMN nombre
TO nombreCompleto;

La estructura final sería: 

estudiantes

idAlumno
nombreCompleto
edad
