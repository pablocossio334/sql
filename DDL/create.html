4. ¿Qué hace CREATE TABLE?

La instrucción CREATE TABLE permite crear una nueva tabla dentro de una base de datos.

Al crear una tabla definimos su nombre, sus columnas, los tipos de datos y las restricciones que deben cumplir los datos.

↑ Anterior | ↓ Siguiente

Sintaxis general

CREATE TABLE nombre_tabla (

    columna1 TIPO,
    columna2 TIPO,
    columna3 TIPO

);

↑ Subir

Ejemplo básico

CREATE TABLE alumnos (

    id INT,
    nombre VARCHAR(100),
    edad INT

);

Este ejemplo crea una tabla llamada alumnos con tres columnas.

Elementos de una columna

Nombre

Identifica a la columna dentro de la tabla. 

nombre

Tipo de dato

Define qué clase de información puede almacenar. 

VARCHAR(100)

Restricciones

Definen reglas que deben cumplir los datos. 

NOT NULL

Tipos de datos comunes

INT

Almacena números enteros. 

edad INT

VARCHAR

Almacena texto de longitud variable. 

nombre VARCHAR(100)

DATE

Almacena fechas. 

fechaNacimiento DATE

DECIMAL

Almacena números con decimales. 

precio DECIMAL(10,2)

5. Restricciones principales

PRIMARY KEY

Identifica de forma única cada registro de una tabla. 

id INT PRIMARY KEY

NOT NULL

Obliga a que una columna tenga un valor. 

nombre VARCHAR(100) NOT NULL

UNIQUE

Evita que se repita el mismo valor. 

email VARCHAR(100) UNIQUE

DEFAULT

Asigna un valor automáticamente cuando no se especifica otro. 

activo BOOLEAN DEFAULT TRUE

↑ Subir | ↓ Siguiente

AUTO_INCREMENT

En MySQL y MariaDB, AUTO_INCREMENT permite generar automáticamente un número para cada nuevo registro. 

id INT PRIMARY KEY AUTO_INCREMENT

Clave foránea

Una FOREIGN KEY permite relacionar una tabla con otra. 

CREATE TABLE alumnos (

    idAlumno INT PRIMARY KEY AUTO_INCREMENT,

    nombre VARCHAR(100) NOT NULL,

    idCurso INT,

    FOREIGN KEY (idCurso)
    REFERENCES cursos(idCurso)

);

En este ejemplo, idCurso guarda un valor que debe existir previamente en la tabla cursos.

6. Clave primaria compuesta

Una tabla puede tener una clave primaria formada por dos o más columnas.

A esto se le llama clave primaria compuesta. 

CREATE TABLE alumnos_cursos (

    idAlumno INT,
    idCurso INT,

    PRIMARY KEY (idAlumno, idCurso)

);

idAlumno puede repetirse y idCurso también puede repetirse.

Lo que no puede repetirse es la combinación: 

(idAlumno, idCurso)

¿Hay dos PRIMARY KEY?

No. Una tabla tiene una sola clave primaria.

Puede estar formada por una columna: 

PRIMARY KEY (idAlumno)

o por varias: 

PRIMARY KEY (idAlumno, idCurso)

Dos claves foráneas

En una tabla intermedia de una relación muchos a muchos es frecuente encontrar dos claves foráneas. 

CREATE TABLE alumnos_cursos (

    idAlumno INT,
    idCurso INT,

    FOREIGN KEY (idAlumno)
    REFERENCES alumnos(idAlumno),

    FOREIGN KEY (idCurso)
    REFERENCES cursos(idCurso)

);

Dos FOREIGN KEY + PRIMARY KEY compuesta

CREATE TABLE alumnos_cursos (

    idAlumno INT,
    idCurso INT,

    PRIMARY KEY (idAlumno, idCurso),

    FOREIGN KEY (idAlumno)
    REFERENCES alumnos(idAlumno),

    FOREIGN KEY (idCurso)
    REFERENCES cursos(idCurso)

);

Las dos columnas funcionan como claves foráneas y al mismo tiempo forman juntas la clave primaria.

Ejemplo completo

CREATE DATABASE escuela;

USE escuela;


CREATE TABLE cursos (

    idCurso INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100)
    NOT NULL

);


CREATE TABLE alumnos (

    idAlumno INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100)
    NOT NULL,

    email VARCHAR(100)
    UNIQUE,

    edad INT,

    idCurso INT,

    FOREIGN KEY (idCurso)
    REFERENCES cursos(idCurso)

);

En este ejemplo primero creamos escuela, la seleccionamos y después creamos las tablas cursos y alumnos.
