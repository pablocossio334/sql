1. ¿Qué hace DROP TABLE?

La instrucción DROP TABLE elimina completamente una tabla de la base de datos.

Se elimina tanto la estructura como todos los datos almacenados dentro de ella.

↑ Subir | ↓ Siguiente

Sintaxis general

DROP TABLE nombre_tabla;

Ejemplo básico

DROP TABLE alumnos;

Este comando elimina completamente la tabla alumnos.

¿Qué se elimina?

Columnas

Se elimina toda la estructura de columnas de la tabla.

Registros

Se eliminan todos los datos almacenados.

Restricciones

Se eliminan PRIMARY KEY, UNIQUE y otras restricciones propias de la tabla.

2. DROP TABLE IF EXISTS

Podemos agregar IF EXISTS para evitar un error si la tabla no existe. 

DROP TABLE IF EXISTS alumnos;

Si la tabla existe, se elimina. Si no existe, MySQL continúa sin producir el error normal de tabla inexistente.

3. Eliminar varias tablas

En MySQL y MariaDB podemos eliminar varias tablas en una misma instrucción. 

DROP TABLE alumnos, cursos, docentes;

También podemos combinarlo con IF EXISTS. 

DROP TABLE IF EXISTS
alumnos,
cursos,
docentes;

4. DROP TABLE y claves foráneas

Si otra tabla tiene una FOREIGN KEY que referencia a la tabla que queremos eliminar, el gestor puede impedir la operación. 

cursos
   ↑
   |
alumnos.idCurso

Por ejemplo, si alumnos.idCurso referencia a cursos.idCurso, puede no ser posible eliminar cursos mientras exista esa relación.

↑ Anterior | ↓ Siguiente

Orden correcto al eliminar tablas relacionadas

Generalmente debemos eliminar primero las tablas que contienen las claves foráneas. 

DROP TABLE alumnos;

DROP TABLE cursos;

Primero eliminamos la tabla dependiente y después la tabla principal.

Tabla intermedia

En una relación muchos a muchos, normalmente eliminamos primero la tabla intermedia. 

alumnos
    ↑
    |
alumnos_cursos
    |
    ↓
cursos

El orden podría ser: 

DROP TABLE alumnos_cursos;

DROP TABLE alumnos;

DROP TABLE cursos;

5. DROP TABLE vs DELETE

DELETE

Elimina registros, pero conserva la tabla. 

DELETE FROM alumnos;

DROP TABLE

Elimina los registros y también la estructura. 

DROP TABLE alumnos;

DROP TABLE vs TRUNCATE TABLE

TRUNCATE

Vacía todos los registros, pero mantiene la tabla. 

TRUNCATE TABLE alumnos;

DROP

Elimina completamente la tabla. 

DROP TABLE alumnos;

Comparación rápida

DELETE
   ↓
Elimina registros
Mantiene estructura


TRUNCATE
   ↓
Elimina todos los registros
Mantiene estructura


DROP TABLE
   ↓
Elimina registros
+
Elimina estructura

6. DROP DATABASE

La instrucción DROP DATABASE elimina completamente una base de datos.

Esto significa que se eliminan todas las tablas, datos y estructuras que contiene. 

DROP DATABASE escuela;

En este ejemplo se elimina completamente la base de datos escuela.

↑ Anterior | ↓ Siguiente

DROP DATABASE IF EXISTS

También podemos utilizar IF EXISTS para evitar un error si la base de datos no existe. 

DROP DATABASE IF EXISTS escuela;

¿Qué elimina DROP DATABASE?

Base de datos

Elimina la base de datos del servidor.

Tablas

Se eliminan todas las tablas contenidas dentro de ella.

Datos

Se eliminan todos los registros almacenados en esas tablas.

Estructura

También desaparecen columnas, claves y relaciones.

DROP TABLE vs DROP DATABASE

DROP TABLE

Elimina solamente una tabla. 

DROP TABLE alumnos;

DROP DATABASE

Elimina toda la base de datos con todas sus tablas. 

DROP DATABASE escuela;

Ejemplo

Supongamos que tenemos: 

escuela
   |
   ├── alumnos
   ├── cursos
   ├── docentes
   └── inscripciones

Si ejecutamos: 

DROP DATABASE escuela;

desaparecerá toda la base de datos junto con todas esas tablas.

7. ⚠️ Atención

Tanto DROP TABLE como DROP DATABASE son operaciones destructivas.

Antes de ejecutarlas debemos comprobar que realmente queremos eliminar esos objetos y sus datos. 

DROP TABLE
     ↓
Elimina una tabla


DROP DATABASE
     ↓
Elimina toda una base de datos
