1. ¿Qué hace ALTER TABLE?

La instrucción ALTER TABLE permite modificar la estructura de una tabla que ya fue creada.

Podemos agregar, modificar, renombrar o eliminar columnas y también agregar o quitar restricciones.

↑ Subir | ↓ Siguiente

Sintaxis general

ALTER TABLE nombre_tabla
operación;

La operación indica qué cambio queremos realizar sobre la estructura de la tabla.

Operaciones principales

ADD

Agregar columnas o restricciones.

MODIFY

Modificar el tipo o propiedades de una columna.

DROP

Eliminar columnas o restricciones.

RENAME

Cambiar el nombre de columnas o de la tabla.

2. ADD

Se utiliza ADD para agregar nuevos elementos a la estructura de una tabla.

Uno de sus usos más comunes es agregar una nueva columna. 

ALTER TABLE alumnos
ADD telefono VARCHAR(20);

En este caso agregamos una columna llamada telefono.

↑ Anterior | ↓ Siguiente

Agregar varias columnas

También podemos agregar varias columnas en una misma instrucción. 

ALTER TABLE alumnos

ADD direccion VARCHAR(150),

ADD fechaNacimiento DATE;

3. MODIFY

En MySQL y MariaDB, MODIFY permite modificar el tipo de dato o las propiedades de una columna. 

ALTER TABLE alumnos
MODIFY nombre VARCHAR(150);

En este ejemplo cambiamos el tamaño permitido para la columna nombre.

↑ Anterior | ↓ Siguiente

Agregar NOT NULL

Podemos modificar una columna para indicar que obligatoriamente debe contener un valor. 

ALTER TABLE alumnos
MODIFY nombre VARCHAR(150) NOT NULL;

Al utilizar MODIFY debemos volver a indicar el tipo de dato.

Agregar AUTO_INCREMENT

ALTER TABLE alumnos
MODIFY idAlumno INT AUTO_INCREMENT;

Esto hace que MySQL genere automáticamente un nuevo número para cada registro.

4. RENAME

Podemos cambiar el nombre de una columna existente. 

ALTER TABLE alumnos
RENAME COLUMN nombre
TO nombreCompleto;

En este caso la columna nombre pasa a llamarse nombreCompleto.

↑ Anterior | ↓ Siguiente

Renombrar una tabla

ALTER TABLE alumnos
RENAME TO estudiantes;

La tabla conserva su estructura y sus datos. Solamente cambia su nombre.

5. DROP

DROP COLUMN permite eliminar una columna de una tabla existente. 

ALTER TABLE alumnos
DROP COLUMN telefono;

Atención: al eliminar la columna también se eliminan todos los datos almacenados en ella.

6. PRIMARY KEY

Podemos agregar una clave primaria después de haber creado la tabla. 

ALTER TABLE alumnos
ADD PRIMARY KEY (idAlumno);

A partir de este momento idAlumno identifica de forma única cada registro.

↑ Anterior | ↓ Siguiente

Clave primaria compuesta

También podemos agregar una clave primaria formada por dos o más columnas. 

ALTER TABLE alumnos_cursos
ADD PRIMARY KEY (idAlumno, idCurso);

Sigue existiendo una sola PRIMARY KEY, pero está formada por dos columnas.

Eliminar la PRIMARY KEY

ALTER TABLE alumnos
DROP PRIMARY KEY;

Esto elimina la restricción de clave primaria de la tabla.

7. FOREIGN KEY

ALTER TABLE también permite crear relaciones entre tablas después de haberlas creado. 

ALTER TABLE alumnos

ADD CONSTRAINT fk_alumno_curso

FOREIGN KEY (idCurso)

REFERENCES cursos(idCurso);

fk_alumno_curso es el nombre que le damos a la restricción.

↑ Anterior | ↓ Siguiente

Agregar dos claves foráneas

Esto es frecuente en tablas intermedias de una relación muchos a muchos. 

ALTER TABLE alumnos_cursos

ADD CONSTRAINT fk_alumno
FOREIGN KEY (idAlumno)
REFERENCES alumnos(idAlumno),

ADD CONSTRAINT fk_curso
FOREIGN KEY (idCurso)
REFERENCES cursos(idCurso);

Eliminar una FOREIGN KEY

Para eliminar una clave foránea necesitamos conocer el nombre de la restricción. 

ALTER TABLE alumnos
DROP FOREIGN KEY fk_alumno_curso;

8. Restricciones

ALTER TABLE también permite agregar diferentes restricciones a columnas existentes.

↑ Anterior | ↓ Siguiente

Agregar UNIQUE

UNIQUE evita valores duplicados. 

ALTER TABLE alumnos

ADD CONSTRAINT uq_email

UNIQUE (email);

Ahora dos alumnos no podrán tener el mismo email.

Agregar DEFAULT

Podemos establecer un valor predeterminado para una columna. 

ALTER TABLE alumnos
ALTER activo SET DEFAULT TRUE;

Si al insertar un registro no especificamos un valor para activo, se utilizará el valor predeterminado.

9. Ejemplo paso a paso

Supongamos que inicialmente tenemos esta tabla: 

CREATE TABLE alumnos (

    idAlumno INT,

    nombre VARCHAR(100)

);

Agregamos una columna para la edad: 

ALTER TABLE alumnos
ADD edad INT;

Agregamos la clave primaria: 

ALTER TABLE alumnos
ADD PRIMARY KEY (idAlumno);

Hacemos obligatorio el nombre: 

ALTER TABLE alumnos
MODIFY nombre VARCHAR(100) NOT NULL;

Finalmente agregamos un email: 

ALTER TABLE alumnos
ADD email VARCHAR(100);

Y hacemos que el email sea único: 

ALTER TABLE alumnos

ADD CONSTRAINT uq_email
UNIQUE (email);
