Data Query Language · Lenguaje de Consulta de Datos

🔎 ¿Qué es DQL?

DQL significa Data Query Language y se utiliza para consultar información almacenada en una base de datos.

La instrucción principal de DQL es: 

SELECT

A partir de SELECT podemos agregar distintas cláusulas para filtrar, ordenar, agrupar o combinar información.

🧩 Estructura de una consulta

Una consulta puede combinar varias cláusulas. 

SELECT columnas
FROM tabla
WHERE condicion
GROUP BY columna
HAVING condicion
ORDER BY columna
LIMIT cantidad;

No todas las cláusulas son obligatorias.

Ejemplo

SELECT nombre, edad
FROM alumnos
WHERE edad >= 18
ORDER BY nombre;

Esta consulta:

SELECT

Indica qué columnas queremos mostrar.

FROM

Indica de qué tabla obtenemos los datos.

WHERE

Filtra solamente los alumnos mayores o iguales a 18.

ORDER BY

Ordena el resultado por nombre.
