Data Query Language · Lenguaje de Consulta de Datos

🔎 ¿Qué es DQL?

DQL significa Data Query Language y se utiliza para consultar información almacenada en una base de datos.

La instrucción principal de DQL es: 

SELECT

A partir de SELECT podemos agregar distintas cláusulas para filtrar, ordenar, agrupar o combinar información.

1. SELECT

SELECT se utiliza para consultar información almacenada en una tabla. 

SELECT *
FROM alumnos;

El símbolo * indica que queremos mostrar todas las columnas.

También podemos elegir columnas específicas. 

SELECT nombre, edad
FROM alumnos;

↑ Anterior | ↓ Siguiente

2. WHERE

WHERE permite filtrar registros utilizando una condición. 

SELECT *
FROM alumnos
WHERE edad >= 18;

Solamente se mostrarán los alumnos que cumplan la condición.

↑ Anterior | ↓ Siguiente

3. DISTINCT

DISTINCT evita mostrar valores repetidos. 

SELECT DISTINCT ciudad
FROM alumnos;

Si varios alumnos viven en la misma ciudad, cada ciudad aparecerá una sola vez.

↑ Anterior | ↓ Siguiente

4. ORDER BY

ORDER BY permite ordenar los resultados. 

SELECT nombre, edad
FROM alumnos
ORDER BY nombre;

Podemos indicar el sentido: 

ORDER BY edad ASC;

ORDER BY edad DESC;

ASC

Orden ascendente.

DESC

Orden descendente.

↑ Anterior | ↓ Siguiente

5. LIMIT

LIMIT permite limitar la cantidad de registros mostrados. 

SELECT *
FROM alumnos
LIMIT 5;

En este caso se mostrarán solamente cinco registros.

↑ Anterior | ↓ Siguiente

6. GROUP BY

GROUP BY agrupa registros que tienen un valor en común. 

SELECT ciudad, COUNT(*)
FROM alumnos
GROUP BY ciudad;

Esta consulta permite conocer cuántos alumnos hay en cada ciudad.

↑ Anterior | ↓ Siguiente

7. HAVING

HAVING permite aplicar condiciones sobre los grupos creados con GROUP BY. 

SELECT ciudad, COUNT(*)
FROM alumnos
GROUP BY ciudad
HAVING COUNT(*) > 5;

Solo se mostrarán las ciudades que tengan más de cinco alumnos.

↑ Anterior | ↓ Siguiente

8. JOIN

JOIN permite combinar información de diferentes tablas relacionadas. 

SELECT alumnos.nombre, cursos.nombre
FROM alumnos
JOIN cursos
ON alumnos.idCurso = cursos.idCurso;

La condición ON indica cómo se relacionan ambas tablas.

↑ Anterior | ↓ Siguiente

9. Funciones de agregación

Algunas funciones permiten realizar cálculos sobre grupos de registros.

COUNT()

Cuenta registros.

SUM()

Suma valores.

AVG()

Calcula el promedio.

MAX()

Obtiene el valor máximo.

MIN()

Obtiene el valor mínimo.

SELECT AVG(edad)
FROM alumnos;

↑ Anterior | ↓ Siguiente

10. Subconsultas

Una subconsulta es una consulta SELECT dentro de otra consulta. 

SELECT nombre
FROM alumnos
WHERE edad > (
    SELECT AVG(edad)
    FROM alumnos
);

Primero se calcula el promedio de edad y luego se muestran los alumnos que están por encima de ese promedio.
