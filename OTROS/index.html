1. SHOW DATABASES

Permite mostrar las bases de datos disponibles en el servidor. 

SHOW DATABASES;

Es útil para conocer qué bases existen antes de seleccionar una.

↑ Anterior | ↓ Siguiente

2. USE

Permite seleccionar la base de datos sobre la que vamos a trabajar. 

USE escuela;

Después de ejecutar este comando, las instrucciones se aplicarán sobre la base seleccionada, salvo que indiquemos otra explícitamente.

↑ Anterior | ↓ Siguiente

3. SHOW TABLES

Muestra todas las tablas de la base de datos actual. 

SHOW TABLES;

Antes debemos haber seleccionado una base de datos con: 

USE escuela;

↑ Anterior | ↓ Siguiente

4. DESCRIBE

Permite ver la estructura de una tabla. 

DESCRIBE alumnos;

También puede utilizarse la forma abreviada: 

DESC alumnos;

Podemos ver información como:

Field

Nombre de la columna.

Type

Tipo de dato.

Null

Indica si acepta NULL.

Key

Información sobre claves.

Default

Valor por defecto.

Extra

Información adicional.

↑ Anterior | ↓ Siguiente

5. SHOW COLUMNS

También permite consultar las columnas de una tabla. 

SHOW COLUMNS
FROM alumnos;

Su resultado es similar al de DESCRIBE. 

DESCRIBE alumnos;

SHOW COLUMNS FROM alumnos;

↑ Anterior | ↓ Siguiente

6. SHOW CREATE TABLE

Permite ver la instrucción utilizada por el servidor para definir una tabla. 

SHOW CREATE TABLE alumnos;

Es especialmente útil para revisar:

Columnas

Definición completa.

PRIMARY KEY

Clave primaria.

FOREIGN KEY

Relaciones con otras tablas.

Restricciones

UNIQUE, DEFAULT y otras.

↑ Anterior | ↓ Siguiente

7. EXPLAIN

EXPLAIN permite analizar cómo el motor piensa ejecutar una consulta. 

EXPLAIN
SELECT *
FROM alumnos
WHERE id = 5;

Puede ayudarnos a entender si la consulta utiliza índices y cómo accede a las tablas.

Es especialmente útil para analizar rendimiento.

↑ Anterior | ↓ Siguiente

8. SHOW VARIABLES

Permite consultar variables de configuración del servidor. 

SHOW VARIABLES;

También podemos buscar una variable específica. 

SHOW VARIABLES
LIKE 'autocommit';

Otro ejemplo: 

SHOW VARIABLES
LIKE 'max_connections';

↑ Anterior | ↓ Siguiente

9. SHOW STATUS

Permite consultar información sobre el estado actual del servidor. 

SHOW STATUS;

También podemos buscar información específica: 

SHOW STATUS
LIKE 'Threads_connected';

Puede utilizarse para conocer datos de conexiones, consultas y funcionamiento del servidor.

↑ Anterior | ↓ Siguiente

10. SET

La instrucción SET permite modificar determinadas variables o configuraciones.

Por ejemplo: 

SET autocommit = 0;

Esto desactiva temporalmente la confirmación automática de transacciones.

Para volver a activarla: 

SET autocommit = 1;

Algunas variables requieren permisos especiales o solo pueden modificarse en determinados niveles.

💡 Recorrido típico

Cuando entramos a un servidor podemos utilizar varios de estos comandos para orientarnos. 

SHOW DATABASES;

USE escuela;

SHOW TABLES;

DESCRIBE alumnos;

SHOW CREATE TABLE alumnos;
