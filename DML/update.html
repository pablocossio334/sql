1. ¿Qué hace UPDATE?

La instrucción UPDATE permite modificar datos que ya existen dentro de una tabla.

Forma parte de las instrucciones DML, porque trabaja directamente con los registros almacenados.

↑ Subir | ↓ Siguiente

2. Sintaxis general

UPDATE nombre_tabla

SET columna = nuevo_valor

WHERE condición;

SET indica qué columna queremos modificar.

WHERE indica qué registros serán modificados.

↑ Anterior | ↓ Siguiente

Ejemplo básico

Supongamos que tenemos: 

idAlumno    nombre    edad
--------------------------
1           Ana       20
2           Juan      25
3           Pedro     18

Queremos cambiar la edad de Ana: 

UPDATE alumnos

SET edad = 21

WHERE idAlumno = 1;

La tabla quedaría: 

idAlumno    nombre    edad
--------------------------
1           Ana       21
2           Juan      25
3           Pedro     18

3. UPDATE y WHERE

La cláusula WHERE permite elegir qué registros serán modificados. 

UPDATE alumnos

SET edad = 30

WHERE idAlumno = 2;

Solamente se modifica el registro cuyo idAlumno = 2.

4. Modificar varias columnas

Podemos cambiar varias columnas en una misma instrucción. 

UPDATE alumnos

SET
    nombre = 'Ana Pérez',
    edad = 22

WHERE idAlumno = 1;

En este caso se modifica el nombre y la edad del mismo registro.

↑ Anterior | ↓ Siguiente

5. UPDATE sin WHERE

Si no utilizamos WHERE, se modifican todos los registros de la tabla. 

UPDATE alumnos

SET activo = TRUE;

Esto asignará TRUE a la columna activo de todos los alumnos.

Atención: olvidar WHERE puede modificar todos los registros sin querer.

↑ Anterior | ↓ Siguiente

6. UPDATE con operaciones

El nuevo valor puede calcularse utilizando el valor anterior. 

UPDATE productos

SET precio = precio + 100;

Todos los precios aumentan en 100.

También podemos usar multiplicaciones: 

UPDATE productos

SET precio = precio * 1.10;

Esto aumenta todos los precios un 10%.

7. Asignar NULL

Si la columna permite valores NULL, podemos eliminar su valor actual. 

UPDATE alumnos

SET telefono = NULL

WHERE idAlumno = 3;

Esto no elimina el registro. Solamente deja la columna telefono sin valor.

↑ Anterior | ↓ Siguiente

8. UPDATE y restricciones

Los nuevos valores deben respetar las restricciones definidas en la tabla.

NOT NULL

No podemos asignar NULL si la columna lo prohíbe.

UNIQUE

No podemos repetir un valor que debe ser único.

FOREIGN KEY

El nuevo valor debe existir en la tabla relacionada.

Tipo de dato

El nuevo valor debe ser compatible con el tipo de la columna.

↑ Anterior | ↓ Siguiente

Ejemplo con FOREIGN KEY

Supongamos que un alumno pertenece al curso 1: 

UPDATE alumnos

SET idCurso = 2

WHERE idAlumno = 5;

Esto funcionará solamente si existe un curso con idCurso = 2.

9. Errores comunes

Olvidar WHERE

Puede modificar todos los registros.

UNIQUE

Intentar repetir un valor único.

FOREIGN KEY

Asignar un valor que no existe en la tabla relacionada.

Tipo incorrecto

Intentar guardar un valor incompatible con la columna.

↑ Anterior | ↓ Siguiente

Buena práctica antes de UPDATE

Antes de modificar registros, podemos realizar un SELECT usando la misma condición. 

SELECT *
FROM alumnos

WHERE idAlumno = 5;

Si el registro mostrado es el que queremos modificar, entonces ejecutamos: 

UPDATE alumnos

SET edad = 24

WHERE idAlumno = 5;

Esto ayuda a evitar modificar registros incorrectos.

Ejemplo paso a paso

Tenemos: 

idAlumno    nombre    edad
--------------------------
1           Ana       20
2           Juan      25
3           Pedro     18

Cambiamos la edad de Ana: 

UPDATE alumnos

SET edad = 21

WHERE idAlumno = 1;

Cambiamos nombre y edad de Juan: 

UPDATE alumnos

SET
    nombre = 'Juan Pérez',
    edad = 26

WHERE idAlumno = 2;

Resultado: 

idAlumno    nombre         edad
-------------------------------
1           Ana            21
2           Juan Pérez     26
3           Pedro          18
