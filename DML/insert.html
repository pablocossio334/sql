1. ¿Qué hace INSERT?

La instrucción INSERT INTO permite agregar nuevos registros dentro de una tabla.

Forma parte de las instrucciones DML, porque trabaja directamente con los datos.

↑ Subir | ↓ Siguiente

2. Sintaxis general

INSERT INTO nombre_tabla
(columna1, columna2, columna3)

VALUES
(valor1, valor2, valor3);

Cada valor debe corresponder con la columna ubicada en la misma posición.

↑ Anterior | ↓ Siguiente

Ejemplo básico

Supongamos que tenemos la tabla: 

alumnos

idAlumno
nombre
edad

Podemos insertar un alumno: 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Ana', 20);

El nuevo registro podría quedar: 

idAlumno    nombre    edad
--------------------------
1           Ana       20

3. Indicar las columnas

Una forma recomendada de utilizar INSERT es indicar explícitamente las columnas. 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Juan', 25);

Esto deja claro qué valor corresponde a cada columna.

nombre

Recibe el valor 'Juan'.

edad

Recibe el valor 25.

4. INSERT sin indicar columnas

También es posible insertar valores sin escribir los nombres de las columnas. 

INSERT INTO alumnos

VALUES
(1, 'Ana', 20);

En este caso debemos indicar todos los valores en el mismo orden en que están definidas las columnas de la tabla.

Por eso suele ser más claro utilizar: 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Ana', 20);

5. Insertar varios registros

Podemos agregar varios registros con una sola instrucción. 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Ana', 20),
('Juan', 25),
('Pedro', 18);

En este caso se agregan tres registros a la tabla. 

nombre    edad
--------------
Ana       20
Juan      25
Pedro     18

6. INSERT y AUTO_INCREMENT

Si una columna está definida como AUTO_INCREMENT, normalmente no necesitamos indicar su valor. 

CREATE TABLE alumnos (

    idAlumno INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100),

    edad INT

);

Entonces insertamos: 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Ana', 20);

MySQL genera automáticamente el valor de idAlumno. 

idAlumno    nombre    edad
--------------------------
1           Ana       20

7. NULL y DEFAULT

Algunas columnas pueden aceptar NULL o tener un valor DEFAULT.

NULL

Indica ausencia de valor. 

INSERT INTO alumnos
(nombre, edad)

VALUES
('Ana', NULL);

DEFAULT

Utiliza el valor predeterminado definido para la columna. 

INSERT INTO usuarios
(nombre, activo)

VALUES
('Ana', DEFAULT);

8. INSERT y FOREIGN KEY

Si una columna es una FOREIGN KEY, el valor que insertamos debe existir en la tabla relacionada.

Por ejemplo: 

cursos

idCurso    nombre
-----------------
1          Java
2          SQL

Podemos insertar un alumno relacionado con el curso 2: 

INSERT INTO alumnos
(nombre, idCurso)

VALUES
('Ana', 2);

Esto funciona porque idCurso = 2 existe en la tabla cursos.

Pero: 

INSERT INTO alumnos
(nombre, idCurso)

VALUES
('Pedro', 99);

puede producir un error si el curso 99 no existe.

9. Errores comunes

Orden incorrecto

Los valores no coinciden con las columnas. 

(nombre, edad)

VALUES
(20, 'Ana');

NOT NULL

Falta un valor obligatorio. 

nombre VARCHAR(100)
NOT NULL

UNIQUE

Se intenta insertar un valor que ya existe.

FOREIGN KEY

Se intenta relacionar con un registro inexistente.

Ejemplo completo

Primero tenemos: 

CREATE TABLE alumnos (

    idAlumno INT
    PRIMARY KEY
    AUTO_INCREMENT,

    nombre VARCHAR(100)
    NOT NULL,

    edad INT,

    email VARCHAR(100)
    UNIQUE

);

Insertamos un registro: 

INSERT INTO alumnos
(nombre, edad, email)

VALUES
(
    'Ana',
    20,
    'ana@email.com'
);

Luego otro: 

INSERT INTO alumnos
(nombre, edad, email)

VALUES
(
    'Juan',
    25,
    'juan@email.com'
);

La tabla podría quedar: 

idAlumno    nombre    edad    email
------------------------------------------
1           Ana       20      ana@email.com
2           Juan      25      juan@email.com
