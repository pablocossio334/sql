Instrucciones DML

Data Manipulation Language

DML agrupa las instrucciones SQL utilizadas para insertar, modificar y eliminar los datos almacenados dentro de las tablas.
➕

INSERT

Permite agregar nuevos registros dentro de una tabla.

INSERT INTO alumnos (nombre, edad)
VALUES ('Ana', 20);
✏️

UPDATE

Permite modificar los datos de registros que ya existen dentro de una tabla.

UPDATE alumnos
SET edad = 21
WHERE id = 1;
🗑️

DELETE

Permite eliminar uno o varios registros almacenados dentro de una tabla.

DELETE FROM alumnos
WHERE id = 1;
