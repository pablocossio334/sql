Instrucciones DCL

Data Control Language

DCL agrupa las instrucciones SQL utilizadas para administrar permisos y controlar qué operaciones pueden realizar los usuarios sobre una base de datos.
🔓

GRANT

Permite otorgar permisos a un usuario para realizar determinadas operaciones sobre una base de datos o tabla.

GRANT SELECT, INSERT
ON escuela.*
TO 'usuario'@'localhost';
🔒

REVOKE

Permite quitar permisos que habían sido otorgados previamente a un usuario.

REVOKE INSERT
ON escuela.*
FROM 'usuario'@'localhost';
