Instrucciones TCL

Transaction Control Language

TCL agrupa las instrucciones SQL utilizadas para controlar transacciones, confirmar cambios o deshacer operaciones realizadas sobre los datos.
▶️

START TRANSACTION

Inicia una transacción. Las operaciones realizadas después podrán confirmarse o deshacerse.

START TRANSACTION;
✅

COMMIT

Confirma definitivamente todos los cambios realizados durante la transacción.

COMMIT;
↩️

ROLLBACK

Deshace los cambios realizados desde el inicio de la transacción o desde un punto de guardado.

ROLLBACK;
📍

SAVEPOINT

Crea un punto de guardado dentro de una transacción al que se puede regresar posteriormente.

SAVEPOINT punto1;
⏪

ROLLBACK TO

Permite deshacer los cambios realizados después de un SAVEPOINT sin cancelar toda la transacción.

ROLLBACK TO punto1;
🗑️

RELEASE SAVEPOINT

Elimina un punto de guardado creado previamente dentro de una transacción.

RELEASE SAVEPOINT punto1;
