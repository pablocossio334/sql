Instrucciones SQL

Clasificación de instrucciones según su función

🏗️

DDL

Data Definition Language

Permite crear, modificar y eliminar la estructura de una base de datos, incluyendo tablas, columnas y restricciones.

✏️

DML

Data Manipulation Language

Se utiliza para agregar, modificar y eliminar los datos almacenados dentro de las tablas.

🔎

DQL

Data Query Language

Permite realizar consultas y recuperar información almacenada dentro de una base de datos.

🔐

DCL

Data Control Language

Se utiliza para administrar permisos, privilegios y accesos de los usuarios a los diferentes recursos de la base de datos.

🔄

TCL

Transaction Control Language

Permite controlar las transacciones, confirmar cambios realizados o deshacer operaciones dentro de la base de datos.

🧰

OTROS

Comandos de utilidad y administración

Incluye instrucciones utilizadas para consultar la estructura, seleccionar bases, inspeccionar tablas y obtener información del servidor o del entorno SQL.
